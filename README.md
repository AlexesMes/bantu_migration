# bantu_migration: The pace of sub-Saharan early farming expansions

All data and scripts required to reproduce the analysis for the paper 'The pace of sub-Saharan early farming expansions' (A.Mes, E.R.Crema, S.Merlo, P.J.Lane; 2026) are located within this repository. The repository is organised into five main directories: _src_, _input_, _scripts_, _data_, _output_.


# Bayesian Analyses
The repository contains data, scripts, and results of an hierarchical Bayesian ICAR model with environmental covariates used to inferred arrival times of early farming dispersals in eastern and southern Africa. In addition, the analysis identifies regions where accelerations and decelerations in dispersal dynamics have occured and assesses the extent to which the variation in dispersal rate can be explained by environmental factors: net primary productivity (NPP) and rugosity. 
All models were defined and fitted using the [nimble](https://r-nimble.org/) R package, with the additional support of custom distributions and utility functions of the [nimbleCarbon](https://CRAN.R-project.org/package=nimbleCarbon) R package. **Please note that the analyses are computationally intensive**


# Folder Structure
* the _input_ folder contains all inputs (such as vegetation and elevation shapefiles) required for the analysis
* the _src_ folder contains all functions inputs required for the analysis
* the _scripts_ folder contains all the R-code scripts for running the analysis and generating the figures
* the _data_ folder contains the data require to reproduce the analysis
* the _output_ folder contains all outputs generated by the scripts, including figures. MCMC posterior samples of all analyses are stored as R image files in this directory.

# Datasets
The datasets required for all analyses are contained in the directory _data_. There are several datasets from different sources, namely the files:
* `SARD_database.csv` contains data from the Southern African Radiocarbon Database. Downloaded from: https://github.com/emmaloftus/Southern-African-Radiocarbon-Database. Publication: Loftus et al., 2019, "An archaeological radiocarbon database for southern Africa" Antiquity. (https://doi.org/10.15184/aqy.2019.75).
* `wanyika_database.csv` contains data from the Wanyika database. For access, see: https://pandoradata.earth/dataset/wanyika. Publication: Iminjili et al., 2025, "A dataset of scientific dates from archaeological sites in eastern Africa spanning 5000 BCE to 1800 CE" Nature Scientific Data. (https://www.nature.com/articles/s41597-025-05138-x).
* `collected_dates.xlsx` contains the EIA dates in Eastern and Southern Africa compiled by Alexes Mes. This data is available under FAIR data principles. 
* The Krapp2021 environmental dataset downloaded from the pastclim package is stored in the _environment_ subfolder in _data_.

# Scripts
* The file `prepare_data.R` (in the _scripts_ folder) contains an R script that pre-processes information contained in the radiocarbon data files listed above and generates the R image files (saved in the _data_ folder): (i) `eastc14.RData` for Bayesian analyses of arrival times over the entire eastern and southern African sample window at a scale of d=3.8 (i.e. 47 hexagonal units); (ii) `eastc14_d29.RData` for Bayesian analyses of arrival times over the entire eastern and southern African sample window at a finer spatial resolution of d=2.9 (i.e. 83 hexagonal units); and (iii) `eastc14_wanAB.RData` for Bayesian analyses of arrival times over the entire eastern and southern African sample window, but where dates from the Wanyika databases have been filtered for grades A and B. In addition, the filed `prepare_data.R` generates `sample_window.RData` and `sample_window_d29.RData`, which contain spatial information defining the sample region and local hexagon areas.
* The file `triangulation.R` (in the _scripts_ folder) generates `trig_d38.RData` and `trig_d29.Rdata` (both saved in the _data_ folder) which contains node and edge information from delaunay triangulation between regional hexagonal areas.
* Also in the _scripts_ folder, `enviro.R` downloads, from the pastclim package, the Krapp2021 environmental dataset into the _environment_ subfolder in _data_. This data is then processed and the scaled NPP and rugosity variables at 2,000BP are saved as `Krapp_enviro_variables.RData` or `Krapp_enviro_variables_d29.RData` depending on the spatial scale (saved in the _data_ folder).
* `Womble_Emodel_d38.R` and `Womble_Emodel_d38_nocov.R` (in the _scripts_ folder) run a Bayesian Hierarchical ICAR model with environmental covariates and without covaites, respectively. Outputs generated are described in the File Relationships section below. Approximate runtime for both scripts: ~ 48 hours.

# Figures
`figures.R` in the _scripts_ folder is used to generate all the figures found in the manuscript (stored in the _figures_ subfolder of _output_). Specifically:
* Figure 1 (fig_sites_map.pdf): lines 85 -- 212
* Figure 2 (fig_arrival_by_time.pdf): lines 213 -- 300
* Figure 3 (fig_wombling_boundaries.png): lines 301 -- 425

Also in the _scripts_ folder is `supp_figures.R` used to generate all the supplementary figures (saved in _figures supplementary_ subfolder) and tables (saved in _tables_ subfolder) found in the supplementary material.
