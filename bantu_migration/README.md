# bantu_migration: Understanding the mechanisms behind geographic variations in the rate of EIA expansion in Eastern and Southern Africa

All data and scripts required to reproduce the analysis are located within this repository. The repository is organised into four main directories: _input_, _scripts_, _data_, _output_.
**Please note that the analyses are computationally intensive**

# Folder Structure
* the _input_ folder contains all inputs (such as vegetation and elevation shapefiles) required for the analysis
* the _scripts_ folder contains all the R-code scripts for running the analysis 
* the _data_ folder contains the data require to reproduce the analysis
* the _output_ folder contains all outputs generated by the scripts, including figures. MCMC posterior samples of all analyses are stored as R image files in this directory.


# Datasets
The datasets required for all analyses are contained in the directory _data_. There are several datasets from different sources, namely the CSV files:
* `SARD_Mar2021_14C.csv` contains data from the Southern African Radiocarbon Database. Downloaded from: https://github.com/emmaloftus/Southern-African-Radiocarbon-Database. See Loftus et al., 2019, "An archaeological radiocarbon database for southern Africa" Antiquity. (https://doi.org/10.15184/aqy.2019.75).
* `HumActCA_Dec2020_14C.csv` contains data from the Human Activity in Central Africa (Archive des datations radiocarbones d’Afrique centrale) Database. Downloaded from: https://zenodo.org/record/4394894 or https://github.com/dirkseidensticker/aDRAC [Latter appears to be more up to date]. See Seidensticker et al., 2021, "Population collapse in Congo rainforest from 400 CE urges reassessment of the Bantu Expansion" (https://www.science.org/doi/full/10.1126/sciadv.abd8352).
* `collected_dates.csv` contains the EIA dates in Eastern and Southern Africa compiled by Alexes Mes. This data is available to be shared, by contacting: akm73@cam.ac.uk


The file `prepare_data.R` (in the _scripts_ folder) contains an R script that pre-processes information contained in the CSV files listed above and generates the R image file `c14.RData` or `eastc14.RData` -- depending if you are interested in the whole of sub-Sahara or only Eastern and Southern Africa as the sample window. `c14.RData`/`eastc14.RData` contain R objects required for the Bayesian analyses. 
The file `elevation.RData` contains SRTM90m elevation data for the Eastern Africa subregion. It is also generated from `prepare_data.R`.
The file `triangulation.R` generates `trig.RData` which contains node and edge information from delaunay triangulation between regional hexagonal areas.
Finally the R image files `tactical_sim_gpqr.RData`, `tactical_sim_phase.RData` and `tactical_sim_ICAR.RData` contains simulated datasets that were used to assess the robustness of the proposed Gaussian Process Quantile Regression, Hierarchical Bayesian Phase Model, and Hierarchical ICAR Model methods, respectively. These were generated using the R scripts `tactical_gpqr_sim.R`, `tactical_phase_sim.R`, and `tactical_ICAR_sim.R` (found in the _scripts_ folder).    

# Bayesian Analyses
The repository contains scripts and results of four different sets of analyses: 
* Bayesian Quantile Regression, 
* Gaussian Process Quantile Regression (GPQR), 
* Hierarchichal Bayesian Phase Model,
* Hierarchichal Bayesian ICAR Model. 

All models were defined and fitted using the [nimble](https://r-nimble.org/) R package, with the additional support of custom distributions and utility functions of the [nimbleCarbon](https://CRAN.R-project.org/package=nimbleCarbon) R package.
